🔐 Manajemen Akun

Admin membuat email dan password login langsung dari aplikasi. UUID Supabase dibuat otomatis dan tidak perlu dimasukkan manual.

🔒 Pembuatan akun menggunakan layanan server Supabase. Password tidak disimpan di database aplikasi Admin.

👨‍🏫 Akun Pengajar AKUN LEMBAGA

Buat akun dengan identitas lembaga. Contoh: habib@shohibulquran.id. Akun otomatis terhubung dengan data pengajar.

Password tidak disimpan di Data Pengajar. UUID akun dibuat otomatis oleh Supabase.

👨‍👩‍👧 Akun Walisantri AKUN LEMBAGA

Satu akun Walisantri dapat digunakan untuk beberapa anak. Buat akun untuk anak pertama, lalu hubungkan saudara lainnya ke akun yang sama.

Password tidak disimpan di Data Santri. UUID akun dibuat otomatis oleh Supabase.

👨‍👩‍👧 Hubungkan Anak ke Akun Walisantri

Gunakan fitur ini untuk keluarga yang memiliki 2–3 anak atau lebih. Tidak membuat akun baru; hanya menambahkan hubungan anak ke akun Walisantri yang sudah ada.

🛡️ Backup & Restore Data v70

Khusus Admin. Backup menyimpan snapshot data yang sedang termuat, termasuk data pembelajaran, doa, presensi, jadwal, SPP, pembayaran, dan keuangan.

Admin dapat menugaskan santri melalui kolom Musyrif/ah / Pengajar pada Data Santri. Pengajar yang login hanya akan melihat santri yang namanya cocok dengan penugasan tersebut.
